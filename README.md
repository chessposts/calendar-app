# Calendar Availability App

An interactive calendar app that allows multiple users to share their availability and find the best meeting times.

## Features

- 🙋 Set your name on first visit
- 📅 Click to select dates and time slots
- 👥 See what times others have chosen
- 🎯 Visual highlighting of overlapping availability
- 💾 Data persists across sessions using Supabase
- ⚡ Real-time updates when others make selections

## Time Slots

- **Morning**: 6:00 AM - 10:00 AM
- **Late Morning**: 10:00 AM - 12:00 PM
- **Afternoon**: 12:00 PM - 5:00 PM
- **Evening**: 5:00 PM - 10:00 PM

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Supabase (PostgreSQL)
- Hosting: Vercel

## Local Development

Simply open `index.html` in your browser. The app connects to Supabase for data storage and real-time updates.

## Deployment

This app is deployed on Vercel. Any push to the main branch will automatically deploy.
